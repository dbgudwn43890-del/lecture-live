# 가격 및 품질을 유지하는 원가 절감

## 반영 사항

- Monthly: $9.99 / 3,000 credits(50시간). 원화 가격은 우선 13,900원.
- Semester: 월 요금의 4배인 $39.96 / 12,000 credits(200시간), 4개월 유효, 자동 갱신 없음. 원화 55,600원. 별도 장기 할인은 적용하지 않음.
- 신규 무료 체험: 300 credits, 14일. 기존 구매·지급 내역은 변경하지 않음.
- 한국어·영어 단일 언어 Deepgram Nova-3 및 한·영 혼용 Soniox 유지. 인식 모델, 질문 모델, 프롬프트, 출력 한도, 질문 횟수 정책을 낮추지 않음.
- DB에서 노트와 요약 생성 권한을 원자적으로 확보해 여러 탭·서버의 중복 호출 방지. 생성 권한 확보 실패 시 모델을 호출하지 않음.
- 작업 종료 시 생성 권한 해제. 중단된 작업은 6분 후 복구 가능. 이전 요청이 새 요청의 권한을 해제하지 못하도록 요청별 토큰 비교.
- 짧은 초기 구간이 뒤쪽 요약을 막던 오류 수정. 조용한 구간의 원문은 계속 보존.
- 요약은 구간마다 바로 저장. 뒤쪽 생성이 실패해도 이미 완료한 구간은 다음 요청에서 재사용.
- 요약용 원문 읽기에 실패하면 불완전한 자료로 모델을 호출하지 않음.
- Sandbox에 새 가격을 생성해 연결. 과거 가격의 미완료 결제를 새 플랜으로 잘못 안내하며 열지 않도록 차단.

## 검증과 범위

타입 검사, 전체 자동 테스트, 배포용 빌드 확인. DB 회귀 검사는 테스트 데이터를 롤백하면서 중복 획득 차단, 만료 복구, 토큰 보호, 소유권·권한을 검증한다. DB 생성 권한 마이그레이션은 연결된 DB에 적용했다.

절감액은 실제 요청량을 측정하기 전에는 확정할 수 없다. 동시 중복 발생 시 두 번의 생성이 한 번으로 줄어들며, 중복이 없던 사용에서는 같은 모델 비용이 든다. DB 호출은 추가된다. 프로세스가 모델 처리 도중 강제 종료되면 이미 공급자에 전달된 요청의 비용까지 취소할 수는 없다.

음성을 잘라 저가 파일 인식 API로 보내기, 무음 자동 차단, 웹 검색 일괄 제거는 품질·녹음 누락·답변 근거에 영향을 줄 수 있어 적용하지 않았다. Deepgram 지원 종료 전에 실제 강의 정확도·지연과 공급자 청구액을 비교해 교체 여부를 결정한다. 지원 잔액 자동 모니터링은 이번 변경에 포함되지 않는다.

현재 변경은 로컬 코드 및 Sandbox 설정이다. 실제 결제 공개·운영 배포는 하지 않았다. Live 전환은 별도 계정 승인·키·상품 설정과 운영 결제 검증이 필요하다.
