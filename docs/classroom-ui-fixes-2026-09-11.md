# 강의실 추가, 자비스 스크롤, 답변 그래프 수정

## 변경

- 강의실 추가: 기존 입력줄의 목록 방향 여백이 없던 배치를 교체했다. 이름 라벨과 전체 폭 입력란, 만들기·취소 버튼, 인라인 오류를 제공한다. 목록과 16px 간격을 유지하며 Escape/취소 후 추가 버튼으로 포커스를 돌린다. 생성 성공 시 데스크톱은 추가 버튼, 모바일은 접힌 뒤에도 보이는 수업 목록 버튼으로 이동한다.
- 자비스: ‘최근 내용으로’ 버튼을 문서 흐름 밖에 배치해 표시 여부가 스크롤 영역 높이를 바꾸지 않게 했다. 컨트롤러는 콘텐츠 높이뿐 아니라 실제 스크롤 가능 범위를 비교해, 창 크기 변화에 따른 브라우저의 위치 보정을 사용자의 위쪽 스크롤로 오인하지 않는다.
- 답변: `lecue-chart` 코드 블록을 실제 React 막대그래프로 표시한다. `stacked-bar`는 그룹별 구성 비율, `bar`는 공통 0 기준의 크기 비교다. 원래 수치와 단위, 범례를 함께 표시하고 좁은 컨테이너에서는 라벨·수치 위, 막대 아래로 배치한다.
- 한국어·영어 질문 지침에 근거 있는 수치에 한해 그래프를 쓰도록 명시했다. 음수, 서로 다른 단위, 근거 없는 수치는 본문·표로 설명한다. 계산한 값은 근거를 설명하도록 했다.
- 모델 출력은 제한된 데이터 필드로만 받는다. 크기·개수·유한한 비음수 값 등을 검증하며 HTML, 임의 스타일, URL 실행을 허용하지 않는다. 기존 Markdown 문서 전체를 유지하고 Streamdown의 코드 블록 렌더러를 확장했다. 스트리밍 중 불완전한 데이터는 대기 문구로 표시한다.

## 검증

- 실제 로컬 Next 서버의 변경 전·후 `npm run check:recording`: CSP, AudioWorklet/Worker, microphone/display-capture 정책, 공개 릴레이 health 전부 통과. 첫 샌드박스 호출은 네트워크 제한으로 실패했고 같은 읽기 전용 호출을 네트워크 접근이 가능한 환경에서 실행해 통과했다.
- 최종 `npm test`: 785/785 통과. recorder, token, live-assist, 질문 API 테스트 포함.
- `node --test workers/stt-relay/index.test.mjs`: 26/26 통과.
- `npm run typecheck`: 통과.
- 변경한 UI 대상 Impeccable 검사: 지적 사항 없음.
- 중간 전체 실행에서 기존 PDF Worker 통합 테스트 한 건이 시작 오류로 실패했다. 해당 코드를 수정하지 않고 단독 5/5 및 최종 전체 실행에서 통과했다.
- 스크롤 회귀 테스트는 수정 전 `[false, true, false]`로 잘못 전환했고 수정 후 `[false, true]`를 유지했다. 실제 위쪽 스크롤은 계속 자동 따라가기를 해제한다.
- 실제 로그인된 로컬 강의실 화면: 데스크톱과 좁은 화면의 추가 폼을 확인했다. 폼·목록 간격 약 16px, 가로 넘침 없음. 자동 포커스, 입력 후 만들기 활성화, Escape 포커스 복귀 확인. 생성 API 호출로 계정 데이터를 추가하지는 않았다.
- 네트워크 없는 별도 테스트 페이지에서 실제 `ListeningIndicator → LectureFlow`, `LearningAnswer`를 불러왔다. 60개 요약부터 1초마다 문장을 추가하며 검증했다. 1,339프레임 동안 내부 높이 364px, 팝업 높이 440px, 팝업 상단 위치 264.5px가 유지됐다. 과거 내용으로 이동→맨 아래로 복귀할 때 버튼 전환은 2회만 발생했다. 과거 내용을 읽는 중에는 새 문장이 추가돼도 읽던 위치를 유지했다.
- 동일 컴포넌트의 밝은/어두운 테마 및 한국어/영어 상태를 확인했다. 351px 뷰포트, 279px 그래프 컨테이너에서도 가로 넘침이 없었다. 구성 막대는 90/10, 20/80%, 크기 비교는 75/100% 너비로 정확히 표시됐다. 부분 응답에서는 JSON이 보이지 않고 완성 후 그래프로 바뀌었다.

## 검증 범위

- 실제 HTTP 검사와 브라우저 렌더링 검증을 수행했다. 자동 테스트의 음성 인식·질문 제공자 응답은 모의 데이터다.
- 실제 마이크/탭 오디오 시작·일시정지·재개·종료 및 실제 모델의 그래프 선택 품질은 이번 UI 변경에서 실행하지 않았다. 캡처, PCM, 토큰, 릴레이, 인증·동의·크레딧, 서버 환경은 변경하지 않았다.
- 기존 로컬 서버를 재시작하거나 기존 녹음 탭을 새로고침하지 않았다. 검증용 새 탭과 별도 정적 테스트 서버를 사용했다.
- 배포하지 않았으며 결과는 로컬 작업본에 반영돼 있다.
