# Credits 기한 정책 변경 기록

최종 확인: 2026-09-08. 최신 요금제·구현·운영 검증은 [월별 크레딧 지급 요금제](monthly-credit-plans-2026-09-07.md)를 따른다.

## 현재 정책

- Monthly·Semester·Half-year·Annual은 매월 2,400 credits를 지급한다. 미사용 월 크레딧은 다음 월 경계에서 만료하고 이월하지 않는다. 마지막 회차도 결제한 이용 기간 종료 시 만료한다.
- Semester·Half-year·Annual은 각각 4개월·6개월·12개월분 선결제이며 자동 재결제하지 않는다. Monthly만 매월 유료 갱신한다.
- Top-up은 초기 요금제 카드에서 분리해 로그인 후 ‘credits 추가’로 구매한다. 1,000 credits를 즉시 지급하며 구매일부터 12개월 동안 사용할 수 있다. 유효한 Top-up 사용에는 활성 플랜이 필요하지 않다.
- 결제·월 지급·Top-up 추가 구매는 기존 잔액의 기한이나 플랜 이용 기간을 연장하지 않는다. 무료 가입 600 credits는 가입 후 14일 동안 유효하다.
- 기존 구매와 계약은 구매 당시 조건을 보존하며, 이미 지급된 수량을 월별 지급으로 바꾸거나 정책 전환만으로 다시 지급하지 않는다.
- 잔액 옆 날짜는 여러 지급분 중 가장 빠른 날짜인 ‘다음 만료’ / ‘Next expiry’다.

## 철회된 초기 설계

2026-09-07에는 결제할 때마다 새 크레딧과 유효한 기존 잔액 전체를 결제일부터 1년으로 연장하는 안을 검토했다. 이후 월 지급 시점에도 같은 연장을 적용하는 안이 있었으나, **둘 다 철회되었다.** 해당 문구·예시는 현재 판매 정책이나 구현 기준으로 사용하지 않는다.

철회된 1년 연장 마이그레이션은 운영 DB에 적용하지 않았다. 초기 연장 SQL 검증은 이전 설계의 이력이며 최종 월별 초기화 정책의 운영 검증 결과로 사용하지 않는다.

## 최종 적용·검증

- 최종 앱 테스트 304개, 타입 검사, 로컬·원격 production 빌드가 성공했다.
- 운영 DB에 적용한 마이그레이션은 `20260907020000_monthly_credit_installments.sql`이다. SHA-256은 `3dd0b73cdab13a3a6ed29c668315752732fe0f1ee36438ef20f6ed37d19f603f`다.
- 적용 트랜잭션 안에서 기존 모든 grants·orders가 적용 전후 동일한지 확인하는 assertion이 통과했다. 읽기 전용 사후 확인에서도 기존 grants·orders 보존, 신규 orders 0건, 철회된 연장안의 컬럼 부재를 확인했다.
- Live 가격 5개와 USD·CAD·EUR·KRW PricePreview 응답을 실제 확인했다. 원본은 `/tmp/lecue-live-monthly-price-preview.json`이다.
- 새 배포를 [www.lecue.app](https://www.lecue.app)으로 전환했고 공개 한·영 요금제 화면을 모바일·데스크톱 4개 조합으로 확인했다. 실제 Paddle KRW 가격과 네 플랜이 표시됐으며 오류·가로 넘침·checkout 요청은 없었다.
- 임시 비밀 키 파일 `.env.paddle-setup.local`은 삭제했다. 전환 전 상태의 역사적 백업은 보존했다.
- 실제 유료 결제와 실제 녹음·전사는 실행하지 않았다. 상세 배포 ID와 검증 범위는 [최신 문서](monthly-credit-plans-2026-09-07.md)를 따른다.
