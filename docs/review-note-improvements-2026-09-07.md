# 복습노트와 답변 읽기 개선 — 2026-09-07

사용자가 승인한 복습노트 개선, 일반 답변 들여쓰기, 사이드바를 접었을 때 소폭 넓어지는 답변 영역을 구현했다. 기존 기본 모델을 유지했고 새 유료 평가 호출이나 사용자 수업의 노트 재생성은 실행하지 않았다.

## 내용과 근거

- 한 문장 요약과 최대 5개의 핵심, 내용에 맞는 단계·하위 설명·비교표·확인 문제를 지원한다. 모든 수업에 같은 수의 도식이나 개념을 강제하지 않는다.
- 실제 질문은 원문과 강의 시각을 서버가 검증하여 개인 질문으로 표시한다. 새 연습 문제는 별도로 표시하고 힌트·정답을 접는다. 과거 노트의 출처 없는 QA는 개인 질문이라고 단정하지 않는다.
- 스크립트·질문·자료를 끝까지 페이지별로 읽고, 조회 실패를 부분 입력 성공으로 처리하지 않는다. T/M 근거 ID를 서버에서 실제 입력과 대조하며, 모델이 만든 임의의 문서 ID나 시각을 저장하지 않는다.
- 이전 AI 답변을 사실의 원본으로 사용하지 않는다. 일반 질문에서도 저장된 AI 개념은 보조 맥락이며 현재 스크립트·자료를 우선하도록 했다.
- 재생성은 검증된 결과가 저장되기 전까지 기존 ready 노트를 보존한다. 프런트엔드도 POST 대기 중 GET 폴링으로 이전 ready 상태를 잘못 읽지 않고, 실패하면 오류 안내와 기존 노트를 함께 표시한다.

- 노트의 표는 좁은 화면에서 표 안에서만 가로 스크롤된다. 목차, 실제 질문 바로가기, 검증된 강의 시점 이동을 제공한다.
- 인쇄 시 힌트와 정답을 펼친 뒤 기존 접힘 상태로 되돌린다. 인쇄를 위해 접힌 자료의 외부 다운로드를 강제로 실행하지 않는다.
