# Lecue 모델·원가·품질 검토

검토일: 2026-09-05. 목표: 누적 순이익 $10,000. 현재 무료 운영 유지.

## 판단

이전 검토는 요금과 사용량 한도에 치우쳤다. **Deepgram 지원을 반영한 현금 지출, 한·영 혼용 품질, 기능별 AI 호출을 비교해야 한다는 지적이 맞다.** 이번에는 실제 호출 코드를 추적하고 공급자의 공식 가격·언어 문서를 대조했다.

현재 조합은 충분히 타당하다. 한국어 중심·영어 수업은 지원받는 Deepgram Nova-3, 한·영 혼용은 Soniox, 질문은 저가 모델인 GPT-5.6 Luna를 쓰는 방향을 유지할 만하다. 다만 실제 한국어 강의의 정확도·지연·실패 비용을 동일 조건으로 비교한 결과가 없으므로 **최적의 조합이라고 입증된 상태는 아니다.**

## 음성 인식: 지원 기간과 이후를 나눠 판단

| 공급자·방식 | 공개 참고 단가 | Lecue에서의 의미 |
|---|---:|---|
| Nova-3 단일 언어, 실시간 | $0.0048/분 = $0.288/시간, 현재 프로모션 | 지원이 적용되는 사용분은 현금 지출과 공개 단가를 분리 |
| Nova-3 전문용어 옵션 | 추가 $0.0013/분 = $0.078/시간 | 옵션 사용 시 합계 $0.366/시간 |
| Nova-3 단일 언어, 파일 | $0.0043/분 = $0.258/시간 | 지원 기간에는 유지할 이유가 큼 |
| Soniox 실시간 | 약 $0.12/시간 | 정액이 아니라 오디오·입력 문맥·출력 텍스트 토큰 과금 |
| Soniox 파일 | 약 $0.10/시간 | 혼용 업로드의 비교 후보 |
| Groq Whisper Large V3 Turbo, 파일 | $0.04/시간 | 업로드 비교 후보. 파일 처리 속도가 빠르다는 것이 실시간 자막 지연이 짧다는 뜻은 아님 |

가격 근거: [Deepgram](https://deepgram.com/pricing), [Soniox](https://soniox.com/pricing), [Groq](https://console.groq.com/docs/speech-to-text). Nova-3 단일 언어 실시간의 프로모션 전 표시 가격은 $0.0077/분이다. 장기 원가를 프로모션 하나로 고정하면 안 된다.

Soniox의 실시간 요율은 100만 토큰당 오디오 입력 $2, 문맥 입력 $4, 텍스트 출력 $4다. 공식 약 $0.12/시간은 오디오 30,000 + 출력 15,000 토큰의 참고치이며, 강의 발화량과 문맥에 따라 달라진다. Groq는 요청당 최소 10초 과금이 있어 작은 오디오 조각을 반복 전송하는 구현은 표시 단가와 실제 비용이 달라질 수 있다. 위 공식 가격 문서 기준.

**Nova-3가 한국어를 지원한다는 것과 multi 모드가 한국어 혼용을 지원한다는 것은 다르다.** 현재 공식 Nova-3 multi 언어 목록에는 한국어가 없다. 따라서 Soniox를 선택한 이유는 기능 요구에 부합한다. [Deepgram 모델·언어 목록](https://developers.deepgram.com/docs/models-languages-overview)

사용자가 제공한 지원 조건은 초기 $1,000, 월 $100, 초기 소진 후 요청 가능한 다음 $5,000이다. 실제 잔액·만료·월 크레딧 이월·차감 순서는 계정에서 별도로 확인해야 한다. 다음 $5,000은 승인 전 확정 재원으로 계산하지 않는다.

위 단가로 단순 계산하면 월 $100은 기본 인식 약 347시간, 전문용어 옵션 포함 약 273시간이다. 초기 $1,000은 각각 약 3,472시간·2,732시간이다. 이는 해당 크레딧 전액을 이 STT에 사용할 때의 환산이며, TTS나 다른 사용분·계약 단가가 있으면 달라진다.

권고: 수업 준비 화면에서 언어를 구체적으로 고르게 한다. 이번에 ‘한국어 중심 / 한국어 + 영어 / English’를 제공하고 저장한 한국어 중심 선택이 혼용으로 덮어써지던 동작을 수정했다. 첫 방문 기본값은 기존처럼 혼용을 유지했다. 모델 이름과 지원 프로그램 사정은 학습자의 설정 화면에 노출하지 않는다.

## 질문·요약: 이미 저렴하지만 호출 방식은 개선할 수 있음

표는 100만 토큰당 표준 요금이며, 긴 문맥·캐시·처리 등급에 따라 달라질 수 있다.

| 후보 | 입력 / 출력 | 권고 |
|---|---:|---|
| GPT-5.6 Luna | $0.20 / $1.20 | 현재 질문·노트의 기준 모델로 유지 |
| GPT-4o mini | $0.15 / $0.60 | 현재 구간 요약의 비교 기준 |
| Gemini 2.5 Flash-Lite | $0.10 / $0.40 | 단순 구간 요약·핵심어 추출의 실험 후보 |
| Gemini 3.1 Flash-Lite | $0.25 / $1.50 | 최신 경량 모델이라는 이유만으로 교체하면 현재 Luna보다 비싸짐 |

근거: [Luna](https://developers.openai.com/api/docs/models/gpt-5.6-luna), [GPT-4o mini](https://developers.openai.com/api/docs/models/gpt-4o-mini), [Gemini 가격](https://ai.google.dev/gemini-api/docs/pricing). Gemini 후보는 지원 수명과 실제 한국어 품질까지 확인한 뒤 도입해야 한다.

가장 먼저 볼 것은 모델명보다 **질문 하나를 제대로 해결하는 총비용**이다. 싼 답변이 잘려 다시 질문하거나 엉뚱한 검색을 수행하면 절감이 사라진다. 어려운 수식·다단계 추론만 상위 모델을 쓰는 방식은 평가 후 고려할 수 있지만, 지금 전부 고급 모델로 바꿀 이유는 없다.

보안과 비용이 만나는 지점도 있다. 브라우저에 발급하는 짧은 수명의 STT 키는 연결 시작을 제한할 뿐, 연결 후의 사용 시간을 앱의 한도로 강제하는 장치와 동일하지 않다. 공급자 사용량과 세션 사용량을 대조하고, 비정상 동시 연결·무료 계정 남용을 먼저 탐지해야 한다. 전부 서버 중계로 바꾸면 강제 제어는 쉬워지지만 인프라 비용·지연이 늘므로 규모에 맞게 판단한다.

## 한 시간 비용 예시 — 실제 관측값이 아닌 계산 시나리오

질문 20회(매회 입력 4,000·과금 출력 400토큰), 요약 5회(매회 입력 2,000·출력 500), 노트 1회(입력 20,000·과금 출력 4,000)라고 가정한다. 과금 출력에는 해당 모델의 추론 토큰도 포함한다고 가정한다. 캐시 할인은 적용하지 않는다.

- 질문: $0.0256
- 요약: $0.0030
- 노트: $0.0088
- 위 세 항목 합계: **$0.0374**

여기에 Soniox 참고 STT $0.12를 더하면 약 $0.1574/시간이다. Deepgram 지원 크레딧으로 STT 전액이 상계된다면 해당 기간의 현금 기준 합계는 약 $0.0374다. 지원 없는 Nova-3 기본 STT라면 약 $0.3254다. 전문용어 옵션·임베딩·문서 추출·검색·실패·인프라·세금·환율 비용은 이 예시에서 제외했다. 검색 10회만 있어도 $0.10과 검색 문맥 비용이 더해진다.

현재 신규 무료 계정에는 코드상 600크레딧, 즉 녹음 기준 최대 10시간이 제공된다. 혼용 STT만으로도 참고 원가 약 $1.20/계정이며 실제 이용량·질문·자료 비용은 별도다. 무료 사용자를 모으는 속도와 비용 한도를 함께 관리해야 한다. `app/lib/free-pilot.ts` 기준이며 기존 계정의 잔액은 다를 수 있다.

누적 순이익 $10,000 판단에는 위 사용량 원가뿐 아니라 무료 체험 비용, 결제 수수료, 환불, 호스팅, 고객 획득비, 고정 운영비가 필요하다. 아직 매출·유지율·이 비용의 관측값이 없으므로 도달 시점을 단정할 수 없다. 지원 적용 후 현금 손익과 지원 종료 후 손익을 나란히 관리하는 것이 적절하다.

## 무엇을 검증해야 ‘가성비가 가장 좋다’고 말할 수 있나

현재 `scripts/eval-stt.mts`는 파일 인식 비교다. Soniox 모델도 `stt-async-preview`로, 실제 서비스의 `stt-rt-v5`와 다르다. CER·용어 재현율은 유용하지만 실시간 첫 자막·최종 확정 지연이나 교실 소음을 대표하지 않는다. 코드 주석의 ‘CER 0%’만으로 운영 품질을 일반화할 수 없다. 평가 파일의 공급자 업로드 정리도 보강해야 한다.

권장 음성 평가: 사용 허락을 받은 2~5분 강의 클립 20개를 한국어 중심, 한·영 문장 혼용, 숫자·수식·전문용어, 먼 거리·소음 조건으로 나눈다. 같은 오디오를 실제 스트리밍 경로로 재생하고 CER, 전문용어·숫자 정확도, 첫 표시/최종 확정 지연의 중앙값·95백분위, 중복·누락, 실제 과금량을 비교한다. 파일 업로드 후보는 별도로 비교한다.

권장 질문 평가: 강의 근거와 정답을 사람이 확인한 질문 50개로 Luna 현재 설정을 기준 삼고, 최근 흐름 요약의 추론량 축소, 구간 요약의 Flash-Lite 대체, 어려운 질문의 제한적 상위 모델 사용을 각각 비교한다. 정확도·수식·근거 일치·학생의 이해 가능성·다시 질문한 비율을 함께 본다. 단순 키워드 포함 여부나 공급자가 공개한 종합 순위만으로 바꾸지 않는다.

이번에는 실제 사용자 강의 음성을 추가 공급자에 보내는 비교 실험이나 유료 모델 교체를 실행하지 않았다. 코드·공식 문서 검토, 직접 추출 경로 수정, 실제 로그인한 로컬 UI 검증을 진행했다. 공급자 교체는 이 평가에서 품질 유지와 총비용 절감이 확인된 뒤 적용하는 것을 권고한다.

## 로컬 로그인 수정 기록

Supabase 대시보드에서 기존 허용 주소가 쿼리 없는 `http://localhost:3000/auth/callback`임을 확인했다. 앱은 `?next=%2Fclassroom`을 붙여 요청하고 있어 `http://localhost:3000/auth/callback?next=*`를 추가했다. 운영 Site URL은 기존 `https://www.lecue.app` 그대로다. 사용자가 재로그인했고 `http://localhost:3000/classroom` 진입을 브라우저에서 확인했다. [Supabase 리디렉션 문서](https://supabase.com/docs/guides/auth/redirect-urls)

## 함께 반영한 강의실 UX와 검증 범위

준비·수업·복습 흐름과 종이색/초록색 디자인을 실제 강의실에 적용했다. 크레딧은 사용자 피드백에 따라 메인에서 제거하고 프로필 메뉴 안에 `숫자 credits`로만 표시한다. 준비 화면의 ‘지난 수업, 이어서 보기’는 제거했다. 기존 수업 목록에서 기록을 열 수 있다.

질문 시점으로 돌아가기, 지난 기록을 읽는 동안 자동 스크롤 멈추기, 실시간 위치로 복귀하기를 연결했다. 종료 후 복습 버튼은 계속 보이며 기록이 없는 종료 세션은 빈 상태를 정확히 안내한다. 설정·복습 창은 브라우저 기본 대화상자를 사용해 Escape와 포커스 복귀를 지원한다. 언어·테마 선택은 방향키로 조작할 수 있다.

실제 로그인한 브라우저에서 수업 복원, 새 수업 준비, 빈 기록, 복습 노트 조회와 닫기, 프로필 안의 크레딧 표시를 확인했다. 1,440px 데스크톱과 390px 모바일에서 배치·가로 넘침·질문 입력창을 확인했고 다크 테마와 키보드 조작을 점검한 뒤 원래 화면 크기와 시스템 테마로 복원했다. 개발 모드의 초기화 재실행이 녹음 종료 잠금을 남겨 수업 열기를 막던 오류도 수정하고 새로고침 후 재확인했다.

자동 검사 117개 통과, 타입 검사 및 배포용 빌드 성공. 이번 검증에서는 실제 마이크 녹음, 새 AI 답변·노트 생성, 장시간 스트리밍 및 공급자 간 음성 품질 비교를 수행하지 않았다. UI 변경과 모델 품질 검증을 같은 것으로 간주하지 않는다. 애플리케이션 변경은 로컬 작업이며 배포하지 않았다.
