DB는 마이그레이션 이후 실제 `auth.users` 생성과 최초 `auth.sessions` 생성을 기록한다. 기존 계정은 소급 등록하지 않는다. 가입 claim에는 인증된 이메일, 사용자와 일치하는 검증된 JWT, 최초 세션, 최근 1시간 이내의 인증 완료, 선택적 분석 동의가 필요하다. 클라이언트가 계정·세션 ID를 요청 본문으로 지정할 수 없고 서비스 역할만 원자적 claim을 실행한다. 여러 탭과 반복 요청은 최대 1회만 성공한다. 최초 세션을 떠난 뒤 재로그인은 신규 가입으로 처리하지 않는다.

가입 기록은 RLS와 서비스 전용 권한으로 보호되며 계정 삭제 시 함께 삭제된다. 선택적 기록 트리거의 오류는 인증을 막지 않도록 처리한다. 분석 오류 때문에 로그인이나 제품 동작이 실패하지 않도록 분리했다.

`claimed_at`은 **한 번의 전송 시도 권한이며 GA4 수신 증거가 아니다**. claim 이후 페이지 종료나 네트워크 실패가 발생하면 중복을 피하기 위해 자동 재전송하지 않아 과소 집계될 수 있다. 기존 기록 초기화나 인위적인 이벤트 재전송으로 검증을 대체하지 않는다.

제품 이벤트에는 내용이나 Lecue 식별자를 넣지 않는다. 같은 화면에서 녹음 재연결·일시정지 후 재개는 추가 시작으로 세지 않고, 이미 완성된 노트를 여는 것도 생성으로 세지 않는다. 완료 시점에 앱을 닫았다면 브라우저가 상태 전환을 관찰하지 못해 집계가 누락될 수 있다. 별도의 Google 전송 작업자는 없다.

## 동의와 데이터 경계

- 분석은 필수 약관·녹음 동의와 분리된 선택 사항이고 기본값은 거부다. 쿠키 설정 링크에서 열고 언제든 철회할 수 있다. 기본 화면을 가리던 고정 버튼은 푸터·개인정보 페이지 링크로 옮겼다.
- 로컬 동의 값과 동의 쿠키가 모두 허용일 때만 비어 있는 별도 동일 출처 문서에서 Google 태그를 로드한다. 동의 전 Google 요청이나 거부 상태 ping을 보내지 않는 방식이다. 로컬·프리뷰는 운영 속성을 로드하지 않는다.
- 분석 문서에는 강의 DOM·폼·인증 URL을 전달하지 않는다. 제목·리퍼러를 고정하고 이벤트 이름과 정제한 위치만 전달한다. 자동 페이지뷰, Google Signals, 맞춤 광고를 끈다.
- 허용 범위는 GA4 자체 가명 식별자, 실제 `gclid`/`gbraid`/`wbraid`, 고정 페이지 분류와 허용된 캠페인 상수다. 이메일·이름·Lecue 계정/강의 세션 ID·강의 내용·질문·답변·스크립트·민감한 URL 값은 보내지 않는다.
- 동의 후 분석/광고 측정 저장소와 광고 측정 데이터만 허용하고 광고 개인화는 계속 거부한다. 철회하면 분석 문서를 제거하고 GA/광고 쿠키를 지우며 다른 탭에 알린다. 클래스룸을 강제 새로고침하지 않는다.
- 분석 쿠키는 갱신 없이 최대 90일, 선택 값은 최대 180일이다. 철회가 이미 전송된 Google 기록을 소급 삭제하는 것은 아니다.

당시 Google 설정은 향상된 측정·Signals·사용자 제공 데이터 수집·광고 개인화 OFF, 이벤트/사용자 보관 2개월, 새 활동에 따른 보관 기간 초기화 OFF였다. Ads 연결의 개인화도 비활성화했고 자동 태그를 선택했다. 리마케팅 잠재고객이나 입찰용 전환은 만들지 않았다.
