## 이번 보완 내용

- 온라인 시청 중 영상에 우선적으로 공간을 배정. 일반 복습의 1240px 상한을 온라인 화면에는 적용하지 않고 질문 패널은 320~400px(중간 폭 310px)로 제한.
- 스크립트는 처음에 숨김. 오른쪽에서 질문↔스크립트를 전환해도 영상 컴포넌트와 공유 스트림 유지. 세 개의 패널을 동시에 좁게 배치하지 않음.
- 시청 시작 시 사이드바 자동 접기, 종료/연결 실패 후 기존 상태 복원. 시청 중 수동 펼치기도 가능하며 저장된 기본 설정은 덮어쓰지 않음.
- 온라인 시청 중 진행 단계 행을 숨기고 설정 버튼을 기록 제어 버튼 옆으로 이동.
- 전체 화면 대상은 영상 하나가 아니라 `workspace-main`. 영상·질문/스크립트·시간·일시정지·종료·설정이 함께 남음. 온라인 시청을 끝내면 해당 전체 화면도 해제.
- 800px 이하에서는 영상 위, 질문/스크립트 아래로 재배치. 원본 영상 비율 유지.
- 좁은 질문 패널에서는 말풍선 폭을 넓히고 한국어 단어 중간 줄바꿈을 줄임. 패널 전환 버튼을 누르면 새 패널 제목으로 키보드 포커스 이동.
- 자동화 재현에서 확인한 `InvalidStateError`를 별도 분류해 Lecue 탭에서 직접 다시 공유하도록 안내. 마이크로 자동 전환하지 않음.
- 새 수업을 눌러도 직전 연결 오류가 남던 현상 추가 수정.

### 실제 공유와 전체 화면의 남은 확인

Chrome 자동화 클릭의 `getDisplayMedia`가 선택창 전에 `InvalidStateError: Invalid state`를 반환했다. 같은 환경의 Fullscreen 요청도 거절됐다. 탭 활성/클릭 활성화 조건과 관련된 자동화 제약 가능성이 있으나 실제 사용자 환경에서도 실패하는 제품 결함이라고 단정하지 않는다. 오류 안내는 보완했지만 성공 경로는 미검증이다.

다음에는 Lecue 탭을 전면에서 직접 조작하여 강의 탭/탭 소리 선택→영상 표시→STT 수신→질문→스크립트 전환→전체 화면→일시정지/재개→브라우저 공유 중단/재선택→종료 시 트랙 해제를 확인해야 한다. 이 항목이 남아 있으므로 문서 전체를 ‘사용 환경까지 완전히 검증 완료’로 표시하지 않는다. 화면 검증용 임시 탭은 정리했으므로 실제 강의 탭으로 진행하면 된다.

## 화면 처리 원칙

Lecue의 영상은 공유한 강의 탭의 미리보기다. 재생·배속·탐색은 원래 강의 탭에서 조절한다. 동작하지 않는 가짜 재생 버튼을 추가하지 않으며, 모든 외부 사이트에서 영상만 자동 추출한다고 약속하지 않는다. 영상은 로컬 표시만 하고 인코딩/서버 업로드하지 않는다. STT에는 기존 오디오 전용 스트림만 전달한다. 종료 후 복습은 기록과 질문 중심이다.

브라우저의 탭/오디오 선택과 매번 권한 요청은 생략할 수 없다. 근거: [MDN getDisplayMedia](https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getDisplayMedia). 외부 탭 스크롤/확대 제어도 일반적인 플레이어 재생 제어와 같지 않다: [Chrome Captured Surface Control](https://developer.chrome.com/docs/web-platform/captured-surface-control).
