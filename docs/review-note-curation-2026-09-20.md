## 변경

- 모든 질문을 반드시 노트에 노출하고 답변 전체를 붙이던 규칙을 제거했다. 학습 의도에 따라 반복·후속 질문을 묶고, 잡담·감사·테스트·무관한 요청·맥락으로도 복원할 수 없는 입력은 사유와 함께 제외한다.
- 짧음·구어체·불만·오타·답변 없음만으로 제외하지 않는다. 서로 다른 조건·수치·반대 의미는 합쳐 흐리지 않는다.
- 동일한 “왜?”도 대화 순서별로 별도 ID를 갖는다. 서로 다른 주제의 같은 문장을 먼저 합쳐 버리던 입력 처리도 수정했다.
- 서버는 각 질문이 묶음 또는 명시적 제외 중 정확히 한 곳에 들어갔는지 검사한다. 출처 없는 미답변 요약, 임의 ID, 중복 처리와 조용한 누락은 거부한다.
- 화면에는 정리된 설명을 먼저 표시하고 원래 질문·AI 답변·차트·풀이를 접어 보존한다. 요약이 없는 기존 노트도 원문을 열 수 있으며 인쇄 시 원문이 빠지지 않게 했다.
- 기존 노트는 자동 재생성하지 않는다. 새로 생성하거나 다시 생성할 때 새 분류·통합이 적용된다. 원래 대화와 DB 스키마는 변경하지 않는다.
