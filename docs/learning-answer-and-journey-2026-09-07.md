# 학습형 답변과 랜딩 → 강의실 UX 개선

2026-09-07. 다른 작업에서 진행한 온라인 화면 보완을 유지하면서, 답변의 학습 가치와 처음 사용하는 흐름을 검토·수정했다. Paddle 계정 인증과 Live 키는 사용자 담당이며 이번 변경 대상이 아니다.

## 판단과 변경

기존 답변은 내용이 좋아도 비교·풀이를 한눈에 보기 어려웠다. 스트리밍과 최종 저장이 다른 표시 방식을 사용했고, 최종 정리 함수가 강조·코드까지 삭제했다. 모델 가격을 높이거나 답변 후 추가 모델을 호출하기 전에 프롬프트·렌더러·저장을 같은 형식으로 맞추는 것이 우선이다.

- 기존 기본 모델, low 추론, 800 출력 토큰 한도 유지. 새 한·영 지시는 핵심 답변 후 필요한 예시/번호 단계/짧은 비교표를 선택하도록 한다. 단답은 짧게 유지한다.
- Streamdown + 수식 플러그인으로 Markdown을 실제 강조·표·목록·수식·코드로 표시한다. 강의실에서 답변이 나타날 때만 컴포넌트를 내려받는다.
- 스트리밍의 빈 강조 기호와 표가 되기 전의 파이프 행을 잠깐 보류한다. 글자별 한·영 테스트로 별표·파이프 노출을 검증했다. 코드 블록의 연산자는 보존한다.
- 확인 문제를 요청하면 문제와 정답을 나누고, 정답은 native details로 접어서 제공한다. 작성 중이거나 스크린리더 완료 안내에서도 정답을 먼저 공개하지 않는다. 형식이 불완전하면 원문으로 안전하게 표시한다.
- 최신 긴 답변 아래 ‘예시로 더 쉽게’와 ‘이해 확인하기’를 배치했다. 클릭할 때만 기존 질문 API를 호출하며, 이전 대화와 원래 질문 시점을 이어 사용한다. 기존 입력 중인 질문은 지우지 않는다.
- 모델 HTML, 원격 이미지, 임베드, 모델이 만든 직접 링크는 실행하지 않는다. 기존 검증된 출처 목록은 유지한다. 저장과 내보내기에서는 코드 연산자·들여쓰기·표를 삭제하지 않는다.
- 시작 버튼을 준비 화면 앞쪽에 배치하고 자료·마이크 설정은 선택 항목으로 접었다. 390px 화면에서 긴 한·영 시작 버튼은 세로로 배치해 단어가 쪼개지지 않는다.
- 로그인 화면의 Lecue. 워드마크·초록 잉크/밝은 바탕·버튼 모서리·패널 그림자를 랜딩과 강의실에 맞췄다.
- 가입 전 체험과 가입 후 무료 credits의 차이를 명확히 하고 온라인 강의 지원을 안내했다. 새 계정의 카드 등록 없이 시작할 수 있다는 설명도 로그인에 추가했다.
- 공개 /en → 강의실에서 기존 한국어 쿠키 때문에 한국어로 바뀌는 실제 버그를 수정했다. 한국어 반대 방향도 확인했다. 기존 언어 우선순위와 공개 SEO 정책은 유지하며, 진입 링크만 현재 화면 언어를 명시한다. 선행 로딩으로 언어 쿠키가 바뀌지 않도록 해당 링크 prefetch는 끈다.
- OAuth callback이 세션 query를 pathname으로 인코딩해 잘못된 URL로 보내는 문제를 수정했다. 실패 재시도와 로그인 중 언어 변경도 기존 목적지를 보존한다.
- 동의 모달은 처음 둘러볼 때 강제하지 않고 기록/파일 선택 전에 확인한다. 미동의·조회 실패 시 기록은 계속 차단한다. ‘먼저 둘러보기’와 Esc를 지원하고 동의 후 다음 행동을 알린다. 캡처 시작을 비동기 동의 뒤에 자동 실행하지 않아 브라우저 활성 클릭을 유지한다.
- 온라인 스크립트의 ‘설명’을 눌러도 답변이 숨겨져 있던 경로를 수정해 질문 패널로 바로 이동한다.

## 검증

- 전체 앱 테스트 173개, 평가 하네스 3개, TypeScript 및 diff 검사 통과.
- 실제 모델에 사용자가 승인한 합성 질문 4건만 전송: 비교·미분 풀이·영문 확인 문제·단답 모두 정상 완료. 추가 재시도 0, 외부 검색 0. 세부 사용량·실제 응답·평가 한계는 `answer-quality-eval-2026-09-07.md`와 `answer-quality-samples-2026-09-07.json`에 기록했다.
- Chrome에서 실제 컴포넌트에 합성 응답을 넣어 표, 수식, 스트리밍, 정답 접기/펼치기를 직접 확인했다. 390 CSS px에서 문서 가로 넘침 없음. 수식이 중간에서 끊기던 부분은 CSS로 보완했다.
- 실제 저장된 2026.9.7 수업의 기존 답변 2개도 새 렌더러로 열었다. 목록·인라인 코드·학습 버튼 정상, 문서 가로 넘침 없음, 해당 탭 오류 로그 없음. 운영 질문을 새로 전송하지 않았다.
- Chrome에서 영문 랜딩의 체험 → 내 강의실, 한국어 랜딩 → 강의실을 따라가 언어 보존을 확인했다. 로그인·OAuth는 자동 회귀 시험이며 새 Google 로그인/법적 동의를 대신 진행하지 않았다.
- 화면 확인용 임시 dev route는 제거했다. 사용자 수업/크레딧 데이터를 수정하는 fixture를 만들지 않았다.
