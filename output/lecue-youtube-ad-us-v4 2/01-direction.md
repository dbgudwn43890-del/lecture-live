# 최종 연출

핵심 경험은 ‘강의를 이미 함께 듣고 있어서, 짧게 물어도 맥락을 아는 AI’다. 수업 내용보다 사용자의 조작과 제품의 반응이 먼저 보이게 한다. 화면 녹화를 길게 보여주는 튜토리얼 대신, 실제 화면 안에서 필요한 부분으로 시선을 이동시킨다.

## 15초 콘티

| 시간 | 화면과 조작 | 편집·사운드 |
|---|---|---|
| 0–1.5초 | 실제 Prepare 화면의 In-person lecture 버튼 클로즈업. 커서가 도착해 한 번 클릭. | 0.15초 누름, 0.25초 화면 전환. 짧고 건조한 클릭음. 시작 화면 전체를 읽게 하지 않는다. |
| 1.5–4.2초 | 실제 Recording 화면. 입력 오디오 표시와 기존 Listening along with you 아이콘이 한 화면에 보인다. | 입력 표시의 작은 움직임과 listening 아이콘의 얇은 링이 같은 리듬으로 세 번 반응한다. 두 요소가 하나의 소리를 받고 있다는 시각적 연결. 효과는 원래 위치에 고정한다. |
| 4.2–6초 | 입력창 위치로 빠르게 이동. 짧은 질문 ‘Can you explain that last part?’가 채워지고 실제 모양의 위쪽 화살표를 한 번 누른다. | 제공된 UI를 기반으로 한 편집 재구성 장면. 1.2초 입력, 0.2초 누름, 0.4초 전환. 이미 쌓인 강의 맥락을 이용하는 시간 압축 몽타주다. |
| 6–11초 | 사용자가 선택한 기존 그래프 답변. 세 줄의 녹색 막대가 왼쪽부터 나타나고 화면이 정착한다. | 원본 픽셀 위의 마스크로 0.7초 reveal. 행간 시작 차이는 0.08초만 둔다. 완성된 그래프를 약 3초 유지. 단어·숫자를 하나씩 강조하지 않는다. |
| 11–13초 | 그래프에서 설명·후속 질문 버튼 쪽으로 짧게 스크롤. | 새 MOV에 담긴 실제 스크롤 감속과 커서 움직임을 참고한다. 기존 그래프 화면을 합성해 움직이며 새 영상의 답변 내용은 쓰지 않는다. 설명문을 읽을 시간을 요구하지 않는다. |
| 13–15초 | Lecue 로고와 lecue.app. | 0.25초 전환 후 마지막 1.5초 이상 안정적으로 유지. |

## 함께 듣는 효과

두 개의 독립된 무작위 펄스는 쓰지 않는다. 동일한 amplitude envelope를 입력 오디오 표시와 listening 아이콘에 함께 적용한다. 1.9초, 2.65초, 3.45초에 약한 박동을 주되 크기를 조금 달리한다. 링은 최대 1.10배, 불투명도 최대 0.22, 0.35초 내 복귀. 새 AI 캐릭터나 떠다니는 오브를 만들지 않는다.

화면 내부의 기능을 설명하는 선이나 화살표도 추가하지 않는다. 기존 두 위치가 함께 반응하고, 이어서 짧은 질문과 풍부한 답변이 나오는 순서 자체로 이해시킨다. 실제 소리 신호를 확보하면 그 envelope에 맞추고, 지금처럼 무음 원본이면 편집용 리듬임을 제작 문서에 명시한다.

## 카피와 오디오

기본은 VO 없는 버전. 원래 UI 문구와 질문 외에 홍보 문구를 화면 위에 얹지 않는다. 제목 자막이나 강의 내용 자막도 없다.

VO가 필요한 배리에이션은 두 문장만 사용한다. 1.7–3.6초: **Lecue listens with you.** 7.0–8.6초: **It heard that, too.** 미국 영어의 담담한 성인 음성. 그래프나 질문을 읽지 않는다. 나머지는 여백을 둔다. 브랜드 발음은 소유자의 지정 발음 사용.

사운드: 시작 클릭 한 번, 가벼운 키 입력, 전송 클릭, 답변 정착 시 낮은 톤 한 번. 펄스마다 알림음을 울리지 않는다. 음악은 목소리·강의 오디오 없는 절제된 리듬. 원본 MOV는 오디오 트랙이 없다.

## 화면 원칙

실제 제품의 아이보리 바탕·녹색·서체·간격을 유지한다. UI 전체를 작게 띄운 카드, 과장된 3D 회전, 실사 배경, 광택 AI 구체, 반짝이, 탄성 과잉 모션은 사용하지 않는다. 질문 입력 장면은 원본 UI 위치와 버튼 형태를 그대로 재구성한다. 비디오에 없는 타이핑이 실제 녹화된 것이라고 표시하지 않는다.

그래프의 제목, 데이터, 단위는 원본 그대로다. 미국 타깃이라는 이유로 원화를 달러로 바꾸지 않는다. 숫자와 내용은 배경 정보이고, 눈에 들어오는 것은 답변의 구조와 막대의 형태다.

원본의 개인정보 사이드바, 브라우저 탭, 디버깅 배너, 한국어 강의명은 화면 밖으로 크롭한다. 답변 캡처와 MOV는 종료된 세션이므로 Recording 표시를 합성해 실시간 연속 녹화처럼 위장하지 않는다. 시작·질문·답변을 시간 압축한 제품 몽타주로 편집한다.

## 제작 출력

1920×1080, 30fps, 450프레임. 세로본은 필요 시 각 UI 크롭을 다시 구성해 1080×1920으로 제작한다. 전체 영상을 중앙 크롭하지 않는다. 먼저 15초 무음 러프와 시작·리스닝·질문·그래프·엔딩 5개 프레임을 만든다. 최종본은 H.264 MP4, 편집 프로젝트, 오디오 스템, VO 채택 시 해당 SRT. 제작 승인과 광고 게시 승인은 별개이며 이 요청은 게시를 포함하지 않는다.
