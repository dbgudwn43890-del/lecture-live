# Lecue / US / 15 seconds / v4

최신 지시를 반영한 제작 인계본. 이전 버전보다 이 문서를 우선한다.

미국 대학생·대학원생 대상, 최대 15초, 실제 제품 화면 중심. 함께 듣는 가치는 기존 녹음 표시와 listening 아이콘이 같은 리듬으로 반응하는 효과로 전달한다. 답변은 사용자가 선택한 기존 세 줄 막대그래프를 사용한다. 새로 제공된 영상은 스크롤과 커서 동작의 소스다.

- `01-direction.md`: 콘티, 모션, 사운드, 카피.
- `02-claude-prompt.md`: Claude에 전달할 영어 제작 프롬프트.
- `03-edit.json`: 30fps, 450프레임 타임라인.
- `04-source-notes.md`: 확보한 원본과 활용 범위.
- `assets/`: 실제 캡처 3장, 10.16초 원본 MOV, 로고.

현재 산출물은 제작 계획과 원본 소스다. 완성 MP4나 실제 연속 사용 녹화본으로 표시하지 않는다. 별도 모션 예시는 실제 스크린샷에 적용할 편집 효과를 보여준다.

엔딩은 Lecue 로고와 lecue.app만 사용한다. 체험 시간 CTA, 추가 슬로건 화면, 강의 내용을 가르치는 장면은 없다. 대사 없이도 작동하는 편집을 기본으로 한다.
