# Lecue 유튜브 광고 제작 패키지

2026-09-11 · 대상: 대학생·대학원생 · 콘셉트: **〈방금, 그 말〉**

**기억시킬 한 문장: 같은 강의를 듣는 AI, Lecue.**

한 단어에서 막혔는데 강의는 계속되는 순간을 보여준다. 사용자는 짧게 질문하고, Lecue는 앞서 나온 강의의 설명을 연결한다. 사용자는 다시 수업을 따라간다.

## 읽는 순서

1. [01-creative-plan.md](01-creative-plan.md): 타깃, 30초 콘티, 조작, 비주얼·사운드, 축약본, 제작 순서.
2. [02-claude-production-prompt.md](02-claude-production-prompt.md): Claude와 연결된 영상 제작 도구에 전달할 실행 지시. 이 파일과 나머지 파일을 함께 제공한다.
3. [03-shotlist.json](03-shotlist.json): 초 단위 장면·음성·화면 텍스트 데이터.
4. [04-copy.txt](04-copy.txt): 확정 카피, 내레이션, 예시 강의·질문·답변.
5. [05-evidence-and-assets.md](05-evidence-and-assets.md): 확인 근거, 실제 기능과 광고 연출의 경계, 브랜드 에셋.
6. [subtitles](subtitles): 30초·15초·6초 내레이션 기준 SRT 초안. 최종 음성에 맞춰 재동기화한다.
7. [assets](assets): 승인된 심볼 마스터와 로고 참고 이미지 원본 사본. 실제 교실 화면은 촬영·합성 단계에서 별도로 확보한다.

## 제작 범위

30초 16:9 본편을 먼저 제작하고, 같은 에셋으로 15초·6초 및 9:16 구성을 만든다. 이번 패키지는 **제작 기획과 콘티**이며 완성 영상이나 실제 성능을 촬영한 데모가 아니다. 공개 랜딩과 데모는 브라우저에서 확인했고, 실제 교실 UI의 라벨과 기능은 로컬 소스에서 확인했다. 실제 마이크·실시간 Q&A와 배포본의 전체 UI 일치는 이번 작업에서 검증하지 않았다.

광고용 강의와 답변은 창작 예시다. UI 조작 장면은 실제 구조를 재현하고, 일반 사용자에게 제공되지 않는 기능은 추가하지 않는다. 제작자가 최종 배포 화면을 확인한 뒤 화면 소스를 확정한다.

## 우선 결정

- 대표 타깃: 노트북으로 전공 강의·세미나를 듣는 대학생·대학원생.
- 대표 효용: 같은 강의의 맥락을 바탕으로, 막힌 대목을 그때 묻기.
- 주요 조작: 질문 입력 → 화살표 전송 → 맥락이 담긴 답변. 수강 시작 절차는 본편에서 생략.
- 전환 목표: 홈페이지의 **30초만 체험하기**. 실제 수업 시작 전 부담 없이 경험하도록 유도.
- 로고: 승인된 folded-L 심볼 계열. 구형 청록·주황 로고를 사용하지 않는다.
