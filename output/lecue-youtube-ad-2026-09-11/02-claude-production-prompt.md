# Claude 영상 제작용 마스터 프롬프트

아래 지시와 함께 `01-creative-plan.md`, `03-shotlist.json`, `04-copy.txt`, `05-evidence-and-assets.md`, 승인된 로고·제품 화면을 제공하세요. 사용자가 지정한 Claude 환경에서 실행하며, 모델명이나 연결된 영상 도구의 기능은 이 문서가 확인한 사실이 아닙니다.

---

당신은 제품 광고의 크리에이티브 디렉터이자 모션 디자이너다. 연결된 영상·합성·음성 도구를 사용해 Lecue의 짧은 유튜브 광고를 제작하라. 타깃은 전공 강의와 세미나를 듣는 대학생·대학원생이다.

**광고명: 〈방금, 그 말〉**

**단 하나의 메시지: 같은 강의를 듣는 AI, Lecue.**

목표는 ‘수업을 기록하는 도구’라는 설명에서 끝나는 것이 아니라, ‘이미 같은 강의를 듣고 있으므로 짧게 물어도 앞의 설명을 연결한다’는 효용을 실제 질문 조작으로 보여주는 것이다. 차분하고 정확하며 제품에 자신 있는 광고여야 한다.

## 확정된 방향

1. 30초 16:9 본편을 먼저 완성한다. 1920×1080, 30fps, 900프레임이다.
2. 같은 에셋으로 15초, 6초 및 각 9:16 버전을 만든다. 단순 배속·중앙 크롭은 하지 않는다.
3. 촬영한 현실처럼 보이는 장면, 인물, 책상, 손, 노트북 외형은 사용하지 않는다. 정교한 2D/2.5D 제품 모션그래픽을 만든다.
4. Grammarly 레퍼런스 https://www.youtube.com/watch?v=JQX7SdUJGeo 에서 큰 제품 UI·입력·결과 중심의 전달 방식을 참고한다. 원본 영상·음악·카피·아이콘은 재사용하지 않는다.
5. 한국어, 로고, UI, 커서는 편집 가능한 레이어로 만든다. 생성형 비디오가 한글과 UI를 직접 그리게 하지 않는다. 제품 조작은 제공된 실제 화면 또는 충실한 재구성 화면에 합성한다.

## 정확한 30초 타임라인

- 0–3초: ‘잠깐. 방금 그 말?’ 한 단어에서 막힌 상황. 강의 문장은 다음으로 흐른다. 작은 Lecue 워드마크는 첫 프레임부터 보인다. VO: ‘강의는 계속되는데,’
- 3–5초: Lecue 실제 교실 화면. ‘통계학’, ‘기록 중’, ‘소리를 함께 듣고 있어요’. VO: ‘그 말에서 막혔다면.’
- 5–10초: ‘이 강의에 대해 질문하세요’ 입력창에서 ‘방금 말한 가중치가 뭐야?’를 입력하고 ↑ ‘질문 보내기’를 누른다. VO: ‘같은 강의를 듣는 AI에게 물어보세요.’
- 10–17초: ‘강의 조교 · AI’ 답변 ‘앞서 말한 PC·모바일 방문자 비율이에요.’를 크게 보여준다. 12–17초에는 답변을 고정한다. VO 없음. 핵심을 읽을 시간을 확보한다.
- 17–23초: 답변 옆/위 실제 ‘기록 중’ 상태와 시간이 계속된다. 다음 강의 문장은 제품 창 바깥의 광고 그래픽이다. 카피: ‘질문하는 동안에도 기록은 계속.’ VO: ‘앞서 나온 내용까지 연결해 설명하니까.’
- 23–27초: 브랜드 문장 ‘같은 강의를 듣는 AI, Lecue.’ VO: ‘같은 강의를 듣는 AI, 레큐.’
- 27–30초: 엔드카드. ‘30초만 체험하기’, ‘lecue.app’, 보조 ‘가입 없이 체험’. VO: ‘지금, 30초만 체험해 보세요.’

## 기능과 UI의 정확성

- 사용자 질문은 타이핑해 전송한다. 자동 음성 질문·자동답변을 일반 기능처럼 그리지 않는다.
- ‘소리를 함께 듣고 있어요’는 현재 소리 수신 상태다. 녹음을 시작하지 않아도 항상 듣고 있는 것처럼 묘사하지 않는다.
- ‘강의 흐름’은 클릭해서 여는 팝오버다. 거대한 상시 전사 패널을 제품에 추가하지 않는다.
- 일반 Q&A에 시간 근거 점프, 데모의 ‘37:05 근거 보기’, 비율 조절 슬라이더를 추가하지 않는다.
- 답변은 예시 강의의 맥락과 연결돼야 한다. 예시 강의: ‘여기서 가중치는 PC와 모바일 방문자의 비율입니다. A는 PC 방문자가 많고, B는 모바일 방문자가 많습니다.’
- 30초 본편 5–23초, 15초 버전 3–11초에 ‘광고용 예시 · 대기 시간 편집’을 읽을 수 있는 작은 글자로 표시한다. 가짜 즉시응답 성능을 연출하지 않는다.
- 숫자 성적 상승, 완벽 이해, 무제한 무료, AI가 모르는 부분을 먼저 알아낸다는 주장은 넣지 않는다.
- 본편은 이미 녹음 중인 상태로 시작한다. 첫 사용 설정·권한 창을 없앤 제품인 것처럼 설명하지 않는다.
- 운영 계정의 개인 강의·사용자 정보가 화면에 들어가지 않게 한다. 진행 중인 녹음이나 서버를 중단해 촬영하지 않는다.

## 미술·모션·소리

광고 배경 #F8F8F2 / 표면 #FFFEFA / 텍스트 #25372C / 녹색 #355E40 / 필요한 단어 강조 #E8EDC9. 실제 앱 UI의 고유 팔레트는 보존한다. Pretendard 한글, Geist 영문, 승인 folded-L 심볼을 사용한다. 구형 `lecue-logo.png`를 파일명만 보고 선택하지 않는다.

큰 타이포그래피, 넓은 여백, 평면 이동, 짧은 마스크 전환, 정돈된 감속을 사용한다. 정확한 클릭과 문장의 관계가 중심이다. 회전하는 UI, 반복 바운스, 그라디언트 AI 구체, 로봇, 회로, 반짝임, 이모지, 파티클, 과한 우시 소리는 사용하지 않는다.

차분한 한국어 성인 음성 한 명. ‘Lecue’는 ‘레큐’, ‘AI’는 ‘에이아이’. 10–17초 내레이션을 비운다. 기본안에 강사 음성을 추가하지 않는다. 음악은 절제된 리듬이며 말과 화면 읽기를 방해하지 않아야 한다.

## 작업 순서

먼저 연결된 도구에서 실제로 가능한 타임라인 편집, 레이어 합성, 벡터·텍스트 렌더, 음성, 자막, 출력 기능을 확인하라. 존재하지 않는 API 이름을 가정하지 말라. 전체 영상을 단일 텍스트-투-비디오 결과에 맡기지 말라.

0초·7초·13초·28초 스타일 프레임 → 30초 러프 애니매틱 → 최종 합성·사운드 → 축약본·세로형 순서로 진행하라. 중간 결과를 검토 가능한 파일로 남겨라. 정해진 기획 안의 일상적 디자인 선택은 직접 해결하라. 근거 없는 제품 기능을 보충해 기획을 확장하지 말라.

정확한 제품 에셋이 없으면 먼저 제공 자료와 공개 배포 화면에서 확인하라. 확인되지 않은 부분은 재구성으로 표시하고 최종본 반영 전 필요한 에셋을 구체적으로 요청하라. 한글·합성이 불가능한 도구밖에 없다면 러프 상태와 부족한 기능을 밝히고, 깨진 화면을 최종본으로 납품하지 말라.

한 번에 모든 컷을 재생성하지 말고 문제가 있는 컷이나 레이어만 수정하라. 유료 생성·추가 도구 설치는 사용자가 허용한 실행 권한과 예산 범위를 따르라.

## 완료 기준

- 소리 없이 봐도 대학 수업, 함께 듣는 AI, 짧은 질문, 맥락 답변, 체험 행동이 이해된다.
- 첫 5초 안에 상황·제품이 보이고, 브랜드는 첫 프레임부터 노출된다.
- 질문을 전송한 뒤 답변이 나온다. 핵심 답변은 최소 4초 이상 안정적으로 읽을 수 있다.
- 작은 화면에서 한국어·버튼·로고가 선명하고 잘리지 않는다.
- 실제 UI에 없는 기능이 없다. 예시·대기 편집 표기가 남아 있다.
- 30/15/6초는 각각 900/450/180프레임이다. 자막은 최종 음성에 맞춘다.
- 최종 MP4, 자막 포함본·클린본, SRT, 편집 프로젝트, 사용 에셋, VO·음악·SFX 분리본을 납품한다.
- 최종 결과와 남아 있는 제약을 짧게 보고한다. 광고 업로드·집행·결제는 별도 요청 없이는 진행하지 않는다.

이제 첨부 자료를 읽고 스타일 프레임부터 제작하라.
